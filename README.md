# Siteau — Рыбная продукция и складской учет

Веб-приложение состоит из двух независимых разделов:
1. **Витрина продукции для покупателей** (`/showcase` или `/vitrine`) — публичный клиентский интерфейс без служебных данных (без PLU и артикулов), с категориями, карточками, описаниями и корзиной/заявкой в кг.
2. **Панель управления складом** (`/admin` или `/dashboard`) — служебная панель с защитой по паролям ролей (Viewer, Editor, Admin), приемкой через PLU-сканер, контролем сроков годности и одноколоночным списком партий.

---

## Запуск приложения

```bash
npm install
npm run dev
```

Сервер запускается на `http://localhost:3000` (`0.0.0.0:3000`).

---

## Роли и учетные данные (RBAC)

Для доступа к защищенным функциям в панели склада или через API передается заголовок `Authorization: Bearer <TOKEN>`:

| Роль | Пароль для входа | Токен | Права |
|------|-----------------|-------|-------|
| **Admin** | `emmamyers` | `token-admin-secret-777` | Полный доступ (удаление партий, удаление из каталога) |
| **Editor** | `jisoo` | `token-editor-secret-555` | Приемка товаров, изменение веса, редактирование каталога |
| **Viewer** | `view` | `token-viewer-secret-111` | Только просмотр складских остатков и каталога |

## Внутренняя техническая документация API (REST Endpoints)

### 1. Авторизация
- **`POST /login`**  
  Тело запроса: `{"password": "..."}`  
  Ответ: `{"token": "...", "role": "admin" | "editor" | "viewer"}`

### 2. Складской учет (партии товаров)
- **`GET /items`** *(Viewer+)*  
  Возвращает список всех текущих партий на складе (сортировка по дате окончания срока годности). Все остатки указаны в **кг**.
- **`GET /items/:id`** *(Viewer+)*  
  Получение партии по ID.
- **`POST /items`** *(Editor+)*  
  Приемка новой партии. Если товар отсутствует в `catalog.json`, он **автоматически сохраняется в каталог** как новая позиция со всеми указанными параметрами.  
  Пример тела:
  ```json
  {
    "plu": "49393",
    "name": "форель карелия 2+",
    "quantity": 15.5,
    "category": "Красная рыба",
    "description": "Свежая охлажденная форель из Карелии",
    "shelf_life": 14,
    "date": {
      "start": "2026-10-31",
      "end": "2026-11-14"
    }
  }
  ```
- **`PUT /items/:id`** *(Editor+)*  
  Обновление партии (вес, даты, наименование, описание, категория).
- **`DELETE /items/:id`** *(Admin)*  
  Списание / удаление партии со склада.

### 3. Справочник каталога
- **`GET /items/scan?code=<PLU>`** *(Публичный)*  
  Быстрый поиск товара в каталоге по коду PLU. Возвращает `{ found, name, weight, shelf_life, description, category, articul }`.
- **`GET /catalog`** *(Публичный)*  
  Получение полного списка позиций из файла `catalog.json`.
- **`POST /catalog`** *(Editor+)*  
  Добавление или обновление позиции в справочнике.
- **`DELETE /catalog/:plu`** *(Admin)*  
  Удаление позиции из справочника `catalog.json`.
